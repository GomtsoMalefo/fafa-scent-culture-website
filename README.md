# FAFA Scent Culture — Luxury Meets Kasi Culture

A responsive, static fragrance storefront built with HTML, CSS and JavaScript. The look blends premium black-and-gold styling with confident South African kasi energy.

## Run locally in VS Code
1. Download and extract this ZIP.
2. In VS Code, choose **File → Open Folder** and select `fafa_scent_culture_website`.
3. Open `index.html` in a browser, or install the **Live Server** extension and select **Go Live**.
4. Keep `images/`, `index.html`, `style.css` and `script.js` together.

## Publish using GitHub Pages
1. Sign in to GitHub and open the intended repository.
2. Upload the contents of this folder to the repository root (so `index.html` is at the root), or use Git from the terminal.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the Pages deployment to finish; GitHub will show the published website URL in Settings → Pages.

Do not upload passwords, access tokens or private credentials to the repository.
